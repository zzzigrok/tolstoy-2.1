# История изменений (Changelog)

Все значимые изменения в проекте **Tolstoy AI** документируются здесь.

## [2.1.0] - 2026-05-02

### Добавлено
- **Prompt Gatherer**: Новый алгоритм семантического сбора промптов для тестирования моделей.
- **Heuristic Syntax Engine**: Движок для автоматической оценки качества генерации (Лингвистический аудит).
- **Rich TUI v2**: Полностью переработанный интерфейс командной строки с панелями и дашбордами.
- **Hardware Autodetect**: Поддержка Intel XPU и улучшенная логика для Apple Silicon (MPS).

### Изменено
- **Структура проекта**: Переход к модульной архитектуре (`core`, `modules`, `engine`).
- **Config**: Параметры модели теперь вынесены в отдельный класс `Config`.
- **Training**: Оптимизирован цикл обучения, добавлена поддержка `torch.compile`.

### Исправлено
- Исправлена ошибка с кодировкой UTF-8 при сохранении логов в Windows.
- Оптимизировано потребление VRAM при инференсе на малых GPU.

## [2.0.0] - 2026-04-15

### Добавлено
- Базовая архитектура Decoder-only Transformer.
- Посимвольная токенизация.
- Первый релиз CLI на базе библиотеки `rich`.

*Проект находится в активной разработке.*
