# Данные (Data)

В этой папке хранятся подготовленные наборы данных и логи работы системы.

- `input_ru.txt`: Очищенный текст для обучения (генерируется `modules/data_cleaner.py`).
- `tolstoy.log`: Системные логи работы CLI и модулей.
- `chat_history.txt`: История ваших диалогов с Tolstoy AI.

> [!NOTE]
> Файлы с данными исключены из репозитория (.gitignore) во избежание переполнения объема хранилища.
