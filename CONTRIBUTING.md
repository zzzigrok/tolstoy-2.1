# Руководство по участию в разработке (Contributing)

Мы приветствуем ваш вклад в развитие **Tolstoy AI**! Проект направлен на стык лингвистики и глубокого обучения, и нам всегда нужны свежие идеи.

## Как вы можете помочь?

1.  **Улучшение датасетов**: Если у вас есть качественно вычитанные тексты русских классиков в формате `.txt`.
2.  **Оптимизация архитектуры**: Идеи по улучшению `SimpleLLM` (например, внедрение RoPE, KV-кэширования или других современных техник).
3.  **Лингвистические эвристики**: Расширение `HeuristicSyntaxEngine` для более точного анализа стилистики.
4.  **Исправление ошибок**: Если вы нашли баг в CLI или логике обучения.

## Процесс разработки

1.  Сделайте **Fork** репозитория.
2.  Создайте ветку для вашей фичи (`git checkout -b feature/cool-feature`).
3.  Внесите изменения и убедитесь, что `cli.py` запускается без ошибок.
4.  Сделайте коммит (`git commit -m 'Add some cool feature'`).
5.  Отправьте ветку в ваш форк (`git push origin feature/cool-feature`).
6.  Откройте **Pull Request**.

## Требования к коду

*   Соблюдайте стиль PEP 8 для Python.
*   Используйте `rich` для вывода в терминал, чтобы сохранить визуальную целостность проекта.
*   Документируйте новые функции и классы.
