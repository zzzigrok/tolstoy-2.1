Технологический Стек

Что делает Tolstoy 2.1 уникальным?

Decoder-Only

Архитектура Transformer, оптимизированная для генерации последовательностей любой длины.

Char-Level

Никаких BPE-токенов. Модель работает напрямую с символами, улавливая тончайшие нюансы синтаксиса.

SDP Attention

Использование Scaled Dot-Product Attention для максимальной скорости обучения и инференса.

12 Layers

Глубокая структура из 12 блоков для извлечения абстрактных семантических связей.
