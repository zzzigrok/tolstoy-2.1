# Модели (Models)

Эта папка предназначена для хранения обученных весов и словарей.

- `model_weights.pth`: Сохраненное состояние (weights) обученного Трансформера.
- `vocab.pkl`: Словарь символов, необходимых для токенизации.

> [!IMPORTANT]
> Веса моделей могут занимать значительный объем (сотни мегабайт), поэтому они не включаются в репозиторий. Используйте `cli.py` для начала обучения и генерации этих файлов.
